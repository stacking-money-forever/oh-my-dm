# 지원 / Support

[한국어](#한국어) · [English](#english)

## 한국어

- 사용 질문과 아이디어: [GitHub Discussions](https://github.com/stacking-money-forever/oh-my-dm/discussions)
- 재현 가능한 버그: [GitHub Issues](https://github.com/stacking-money-forever/oh-my-dm/issues/new/choose)
- 보안 취약점: [SECURITY.md](SECURITY.md)의 비공개 제보 절차

도움을 요청하기 전에 `oh-my-dm doctor`를 실행하고 기존 discussion과 issue를 검색해 주세요. 로그와 스크린샷에서는 개인정보, 계정 ID, 대화 내용, 쿠키와 세션 정보를 모두 제거해야 합니다. 카카오톡 지원은 macOS로 제한됩니다. Instagram과 카카오톡 UI가 변경되면 connector가 일시적으로 동작하지 않을 수 있습니다.

버그를 제보할 때는 oh-my-dm 버전, 운영체제, 터미널, 재현 단계, 예상 동작과 실제 동작을 포함해 주세요. 실제 대화 대신 개인정보를 제거한 최소 fixture를 사용하세요.

## English

- Usage questions and ideas: [GitHub Discussions](https://github.com/stacking-money-forever/oh-my-dm/discussions)
- Reproducible bugs: [GitHub Issues](https://github.com/stacking-money-forever/oh-my-dm/issues/new/choose)
- Security vulnerabilities: follow the private reporting process in [SECURITY.md](SECURITY.md)

Before asking for help, run `oh-my-dm doctor` and search existing discussions and issues. Remove personal information, account IDs, chat content, cookies, and session data from all logs and screenshots. KakaoTalk support is limited to macOS. Instagram and KakaoTalk UI changes may temporarily break connectors.

Bug reports should include the oh-my-dm version, operating system, terminal, reproduction steps, expected behavior, and actual behavior. Use a minimal sanitized fixture instead of a real conversation.
